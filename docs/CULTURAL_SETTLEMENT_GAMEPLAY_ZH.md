# FFPA 文化安置系统：机制逻辑与玩法说明

本文面向玩家和整合包维护者，说明 FFPA — Cultural Settlement System 0.3.0 在 Victoria 3 1.13 中实际加入的机制、操作方式、数值规则、AI 行为与限制。本文以当前脚本实现为准；它描述的是“文化安置”系统，而不是原版殖民系统的一层数值修正。

## 一、这个 Mod 改变了什么

当一个国家采用“殖民安置”（`law_colonial_resettlement`）或“边疆殖民”（`law_frontier_colonization`）法律时，本 Mod 会接管其新殖民地的建立途径：

- 原版“建立殖民地”命令会因为殖民增长生成值被压到负数而在执行前失效，不能生成原版殖民据点。
- 公司不能获得殖民特许状，因而也不能替该国绕过文化安置系统建立原版殖民地。
- 原版 AI 的殖民战略地区评分对这两部法律关闭，AI 改用本 Mod 的外交行动。
- “殖民剥削”不受影响，仍走原版流程。
- 殖民事务制度继续存在，其等级仍决定并行项目上限与项目速度。

新的核心限制是：**只能安置在本国至少一种主流文化的故土州，而且该州必须由分权国家拥有。** 这条限制同时约束玩家和 AI，不是可被高分或高速度绕过的偏好。

## 二、玩家如何发起文化安置

1. 采用“殖民安置”或“边疆殖民”法律并研究“殖民”科技。
2. 打开外交行动，在“常规”组中选择“建立文化安置点”。
3. 选择一个分权国家作为目标国。
4. 在该国境内选择一个满足全部条件的州。
5. 行动立即生效，不需要目标国批准。陆路项目不收费；海路项目立即从国库扣除 **100,000**。

该行动被视为敌对外交行动，并会为目标国制造数值为 **5** 的外交事件影响。启动后，项目标记保存在目标国仍控制的州范围上。

## 三、开工条件

### 3.1 行动国条件

| 条件 | 具体要求 |
|---|---|
| 国家类型 | 必须是受认可或不受认可国家，不能是分权国家 |
| 法律 | 必须采用“殖民安置”或“边疆殖民” |
| 科技 | 必须已研究“殖民” |
| 战争 | 行动国当前不能处于任何战争中 |
| 财政 | 不能处于违约状态 |
| 项目数 | 当前项目数必须低于殖民事务制度所给上限 |

脚本不会单独检查海路项目的国库余额；海路行动成功时直接执行 `-100,000` 国库变化。

### 3.2 目标州条件

目标州必须同时满足：

- 由分权国家拥有；
- 是行动国至少一种主流文化的故土；
- 没有其他正在运行的 FFCS 文化安置项目；
- 目标所有者不是行动国当前外交博弈中的敌方；
- 行动国对目标所在战略地区拥有达到殖民宣称最低档位的利益；
- 存在陆路或海路进入条件；
- 若该州具有严重疟疾特征，行动国必须已经研究奎宁。

### 3.3 陆路与海路条件

满足以下任一条真实省份路线即可：

- **陆路：**目标原所有者控制的至少一个省份，与行动国控制的省份共享实际地图边界；
- **海路：**目标州与行动国领土仅隔一个海域节点、目标州沿海、行动国国内至少有一个港口，而且目标原所有者仍控制该州定义的港口省份。

若两种路线同时成立，系统固定选择陆路，因此不会收取海路费用。项目启动时会保存路线类型，之后不会在陆路与海路之间自动切换。仅仅拥有相邻州范围而没有真实省份接壤不算陆路；仅仅拥有港口也不能安置世界另一端的沿海州、内陆州或港口省份已被第三方占领的州。

### 3.4 并行项目上限

每级殖民事务制度提供两个并行项目槽位：

| 殖民事务制度等级 | 最大并行项目数 |
|---:|---:|
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |
| 5 | 10 |

降低制度等级不会取消已经运行的项目，但在现有项目数重新低于新上限前不能再开工。

## 四、项目如何推进

项目由目标国的每月国家脉冲推进。只有持有“入境安置项目”计数的国家才会扫描自己的州，普通国家不会每月扫描世界全部州。

### 4.1 每月进度公式

每个项目的基础月进度可概括为：

```text
月进度 = max(1,
  (5
   + 殖民事务等级奖励
   + 科技奖励
   + 陆地相邻奖励
   - 动乱惩罚)
  × 严重疟疾倍率
  ÷ 行动国当前并行项目数)
```

各项数值如下：

| 来源 | 月进度变化 |
|---|---:|
| 基础值 | +5 |
| 殖民事务等级 1/2/3/4/5 | +2/+4/+6/+8/+10 |
| 奎宁 | +2 |
| 文明使命 | +3 |
| 与目标州陆地相邻 | +3 |
| 目标州动乱不低于 25% | -2 |
| 严重疟疾且未研究疟疾预防 | 上述结果 ×0.5 |
| 并行项目 | 再除以行动国当前项目总数 |
| 最低进度 | 每月不少于 1 |

奎宁既是进入严重疟疾州的开工门槛，也提供固定速度奖励；疟疾预防则会消除严重疟疾的减半倍率。

并行项目会平分同一国家的行政能力。例如，同时运行两个项目时，两者都用完整修正结果除以 2。多开项目可以同步铺开领土，但会延后每个项目到达下一阶段的时间，也会增加项目在抵抗上限前未能完工的风险。

### 4.2 四个领土扩张阶段

行动被接受时，项目直接初始化到 25 进度并沿当前有效前沿转移第一批省份；若目标州当前只剩一个省份，则直接完成整个项目。其他项目之后达到阈值时继续扩张：

| 累计进度 | 结果 |
|---:|---|
| 接受行动（初始化为 25） | 第 1 阶段：立即取得路线种子并沿项目边界扩张，发送“安置据点建立”通知 |
| 低于 50 | 若进度受挫回落，不撤销既有据点，也不追加转移 |
| 50 | 第 2 阶段：继续连片扩张 |
| 75 | 第 3 阶段：继续连片扩张 |
| 95 | 第 4 阶段：沿仍有效的项目边界尽量只留下一个省份 |
| 100 | 完成：取得仍与本项目连续的最后省份；断开的岛屿、飞地或被第三方隔开的地块保留给原所有者 |

一次月度结算可以跨过多个阈值；脚本会依次补做所有尚未执行的阶段，然后在达到 100 时完成项目。

Mod 从最终 Firefall 地图预先生成字面省份邻接数据库，但会在运行时按照当前所有权选择实际路线：

- 陆路项目按省份 ID 稳定选择第一个“由原目标所有者控制且真实接壤行动国领土”的省份作为种子；
- 海路项目以目标州定义的港口省份为种子；
- 后续省份必须仍由原目标所有者控制，并直接邻接本项目此前取得且仍由行动国控制的省份；
- 同一行动国在州内其他位置的领土不会成为这个项目的第二个扩张起点。

每阶段的转移预算根据该阶段开始时目标州的剩余省份数计算：

```text
阶段预算 = ceil((当前剩余省份数 - 1) ÷ 剩余阶段数)
```

接受行动、50、75、95 进度的剩余阶段数依次为 4、3、2、1，第一块种子计入立即执行的第一阶段预算。扫描会在用完预算、找不到连续前沿或目标州只剩一个省份时停止。100 进度只会接收仍与项目边界相连的最后省份，不会跨越断点强制吞并整州。

海路种子的港口省份在行动被接受时实际转移，系统随即在行动国对应的州创建 1 级港口；若已存在港口则不会升级。完成后，行动国在该州地区内尚未整合的州会明确保持为未整合州，已经整合的州不会被降级。

## 五、抵抗、受挫与时间上限

### 5.1 初始抵抗

项目启动时的抵抗值为：

```text
初始抵抗 = 10 + min(目标州启动时人口 ÷ 100,000, 30)
```

这意味着初始抵抗介于 10 与 40 之间。约 100 万人口的州从 20 开始，300 万及以上人口的州从上限 40 开始。人口只在开工时用于计算这次初始值。

### 5.2 每月变化

- 每月推进后，抵抗固定增加 1；当前没有降低抵抗的机制。
- 抵抗达到 40 后，每月有 5% 权重触发一次“安置受挫”，扣除 10 点进度。
- 受挫不会让进度低于 0。
- 抵抗达到 100 时，项目立即取消；该取消判定优先于当月后续阶段转移和完成。

因此项目存在硬性时间窗口：初始抵抗为 40 时最多约有 60 次月度推进，初始抵抗接近 10 时最多约有 90 次。高人口、低速度、过多并行项目、严重疟疾和高动乱叠加时，失败风险最高。

## 六、持续有效性与自动取消

项目每月会重新检查：

- 发起国仍采用“殖民安置”或“边疆殖民”；
- 发起国仍有“殖民”科技，且仍是受认可或不受认可国家；
- 目标州仍是发起国主流文化故土；
- 目标州剩余部分仍归启动时的原所有者，且该所有者仍是分权国家；
- 项目仍带有启动时保存的 v2 路线；
- 尚未取得种子时，陆路仍有真实省份边界，或海路仍满足“目标沿海、本国有港口、港口省份仍归原所有者”；
- 取得种子后，至少一个本项目记录的省份仍由发起国控制；海路还要求发起国仍控制港口省份、对应州仍有港口建筑且国内仍有港口能力；
- 发起国没有成为当前目标所有者的外交博弈敌方。

任何一项失败都会自动取消项目。若战争、其他事件或其他 Mod 从外部改变了目标州剩余部分的所有权，所有权变化回调也会立即取消项目。FFCS 自己的阶段性省份转移带有内部保护，不会误触发这条取消逻辑。

以下条件只在开工时检查，之后不会单独导致取消：

- 战略地区利益档位；
- 行动国是否处于其他战争；
- 行动国是否违约；
- 当前项目数是否高于后来降低的制度上限。

项目取消会清理项目标记和双方计数，但有两个重要后果：

1. 海路项目已支付的 100,000 不会退还；陆路项目没有启动费用。
2. 之前阶段已经转移给发起国的省份不会自动归还，已经建立的海路港口也不会拆除。

换言之，取消会停止尚未完成的扩张，不会回滚已经形成的领土结果。

## 七、玩家能看到的反馈

文化安置项目会在目标州显示一个同名项目修正。这个修正仅用作可见标记，本身不提供隐藏增益或惩罚。

当至少有一个项目运行时，日志面板会出现“文化安置”条目，逐项显示：

- 目标州与当前所有者；
- 陆路或海路路线；
- 当前阶段名称；
- 0—100 进度条与数值；
- 按当前公式计算的每月增长；
- 0—100 抵抗值。

点击项目行可打开对应州。该列表直接读取项目州变量；每月调度也会重建索引，因此升级后载入已有项目的旧存档，会在下一次月度脉冲自动补出日志条目。

系统会发送七类通知：

- “安置据点建立”：首次省份转移；
- “安置受挫”：抵抗造成 -10 进度；
- “文化安置扩张”：达到 50 进度并执行第 2 阶段；
- “文化安置巩固”：达到 75 进度并执行第 3 阶段；
- “文化安置即将完成”：达到 95 进度且当月尚未直接完成；
- “文化安置完成”：项目达到 100，本项目能够连续抵达的领土扩张结束；
- “文化安置取消”：法律、文化、领土、进入条件、敌对关系或抵抗使项目无法继续。

当前版本仍没有暂停按钮或手动取消按钮。

## 八、AI 如何使用该机制

AI 通过与玩家相同的“建立文化安置点”外交行动开工，并使用完全相同的硬性州资格检查。AI 评分不能绕过主流文化故土、分权所有者、进入条件、疟疾科技或战略利益要求。

AI 只有在法律、科技、非违约、非战争和项目上限条件均满足时才获得评估机会：

- 列强增加 0.10 的评估值；
- 主要国家增加 0.05；
- 殖民型国家或公司国家再增加 0.05。

这些值由游戏外交行动 AI 的评估周期使用，不代表“每月必有对应百分比概率”。

对已经合法的候选州，AI 从基础 10 分开始：

| 情况 | 评分变化 |
|---|---:|
| 与目标州陆地相邻 | +50 |
| 不相邻 | 基础分先 ×0.25 |
| 对目标州有宣称 | +40 |
| 同一州地区内已有本国领土 | +30 |
| 目标州沿海 | +10 |

因此 AI 明显偏好陆地相邻、有宣称、能与既有领土拼接的沿海目标，但在满足硬条件时仍可选择远程沿海故土州。原版 `stance_colonize_region` 对采用这两部 FFCS 法律的 AI 被关闭，避免它继续为已失效的原版殖民命令分配战略评分。

## 九、实用玩法建议

- **优先真实接壤的陆路目标。** 陆路项目免费；州级相邻还会增加每月 3 点进度，并是 AI 的最大单项候选加分。
- **为海路项目预留 100,000。** 费用在接受行动时立即扣除，港口省份和 1 级港口也在接受时建立；项目取消不退款。
- **不要只看并行上限。** 槽位越多不等于单个项目越快；所有项目平分速度。抵抗只增不减，过度铺开可能让项目在 100 抵抗前无法完成。
- **先处理高动乱。** 25% 是明确分界线，达到后每月少 2 点基础进度。
- **把疟疾科技分成两层理解。** 奎宁让严重疟疾州可以开工并加速；疟疾预防才会移除严重疟疾的 0.5 倍速度惩罚。
- **高人口州更赶时间。** 300 万及以上人口会从 40 抵抗起步，第一轮月度推进后就进入每月受挫判定区间。
- **保护项目自己的扩张前沿。** 后续省份只能从这个项目已取得且仍由本国控制的省份继续扩张；全部前沿丢失会取消项目。
- **不要指望一个项目跨越断点。** 岛屿、飞地或第三方阻隔地块会留给原所有者，需要满足新的陆路或海路条件后另开项目。
- **改变法律或失去进入路线前先评估后果。** 项目会取消，海路费用不退，但已经取得的阶段领土与已建港口保留。
- **制度降级不会强拆项目。** 可以让现有项目继续，但在数量降到新上限以下前无法新增项目。
- **战略利益可以在开工后调整。** 失去该利益本身不会取消项目，但其他持续条件仍必须满足。

## 十、与原版殖民的差异和限制

| 原版概念 | FFCS 实现 |
|---|---|
| 原版建立殖民地地图命令 | 对“殖民安置”和“边疆殖民”禁用，改用外交行动 |
| 目标限制 | 主流文化故土州硬限制 |
| 进入路线 | 真实省份接壤的陆路，或仅隔一个海域节点直达目标港口省份的海路 |
| 初始据点 | 接受行动时立即取得陆路边界种子或海路港口种子 |
| 逐省扩张 | 近似为四批、只沿本项目实时连续前沿转移 |
| 海路费用与港口 | 开工扣除 100,000；取得港口省份后补建 1 级港口 |
| 多殖民地分摊增长 | 由并行项目数平分月进度 |
| 原版殖民地对象 | 不创建 |
| 原版殖民紧张度与起义调度 | 不使用；改为抵抗、受挫和自动取消 |
| 完成后的领土 | 只取得连续地块；新形成的未整合州保持未整合，既有整合州不降级 |
| 暂停/恢复 | 当前未实现 |
| 公司殖民特许状 | “殖民安置”和“边疆殖民”法律下不可用 |

由于 Victoria 3 1.13 没有把原版殖民地对象、殖民紧张度和内部逐省增长调度完整开放给通用脚本，本系统复现的是可见的“据点—扩张—完成”流程，而不是生成一个原版殖民地对象。项目进行期间获得的领土是真实领土，但项目本身由州变量、项目省份列表和月度脚本维护。

旧存档中已经存在的原版殖民地或公司特许不会被本 Mod 强制删除或转移；只要其所有者继续采用“殖民安置”或“边疆殖民”，这些原版殖民地就不会继续获得殖民增长。0.3.0 以前启动的 FFCS 项目没有可证明的路线与前沿记录，会在下次月度检查时安全取消：既有领土保留，旧费用不退，双方项目计数正常回收。新项目统一使用 v2 路线和项目省份列表。

## 十一、兼容性与加载顺序

本 Mod 针对以下最终数据库和加载顺序设计：

1. `[1.13] Tech & Res`
2. `2050: The Fire Falls`
3. `2050 Firefall — Core Balance Adapter`
4. `FFPA — Cultural Settlement System`

它依赖最终 Firefall 州地区与省份地图生成省份路线触发器和阶段扩张效果，并依赖最终法律、公司特许和 AI 战略定义完成原版路径封锁。改变加载顺序，或在本 Mod 之后加载会重写这些定义的其他 Mod，可能重新开放原版殖民、改变公司特许条件，或使生成的省份邻接数据与地图不一致。

当前项目计数、发起国、原所有者、进度、阶段、抵抗、路线和项目省份列表均写入存档变量，因此 0.3.0 新项目可跨存档继续。若上游地图、文化故土、法律或 AI 表发生变化，应重新验证生成数据和最终合并结果。
